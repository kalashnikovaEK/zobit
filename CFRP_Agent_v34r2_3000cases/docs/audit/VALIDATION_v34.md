# [NEW v34] 통합 및 독립 검증 결과

v33를 기반으로 웹 실행 전 해석 확인 절차를 추가했습니다. 기존 자연어 의미 검증을 우회하지 않습니다. 기본 물리 모델, UI와 700건 데이터/저장 모델은 유지합니다.

## 반영 사항

- 웹 채팅: 목표·작업·변경/고정 변수·전체 적용 수치·제약을 표시한 후 명시적 실행 확인.
- 승인된 해석과 원 요청/입력/프로필을 저장하고 동일 해석으로 실행. 재해석 LLM 호출 없음.
- 승인 전 모델 로드/물리 계산 없음. 토큰 10분, 1회 사용. 변경된 입력 및 재사용 차단.
- 쉼표로 연결한 변경·고정 절의 2차 승온속도 누락 수정. 공동 단계 및 소수 쉼표 보존.
- 부정된 제약 방향은 자동 해석 대신 명확한 최종 조건 요청.
- 기존 Python 호출 기본값 유지: 추가 선택 인자는 preview_only=None.
