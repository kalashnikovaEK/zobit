# [NEW v28] 디버깅 및 충돌 점검

## 발견 및 수정

사용자 창의 z-index가 목록 메뉴보다 높아, 열린 창 위에 목록이 보이지 않고 클릭이 창에 전달됐습니다. menu_ui_v23.js에 독립 CSS 삽입을 추가하여 열린 메뉴를 최상위에 표시했습니다. 수정 후 사용자 창 3개 동시 열기를 실제 브라우저에서 확인했습니다. 물리·AI·700개 사례 및 저장 모델 파일은 변경하지 않았습니다.
