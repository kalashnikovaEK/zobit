# 물리모델 합성데이터 700건 학습 v24
<!-- [NEW v24] 기존 v23 자산을 보존하고 700건 모델을 별도로 추가한다. -->

총 **700건**으로 대리모델 학습을 완료했다. 기존 물리모델 합성데이터 256건에 실제 물리계산 444건을 추가했다. 임의 정답·복제·보간으로 데이터 수를 늘리지 않았다. 기존 CSV와 v23 모델 파일은 보존했다. LLM 가중치 미세조정이 아닌 Random Forest 대리모델 학습이다.

추가 444건은 Latin Hypercube로 추출한 111개 공정에 각각 4개 두께를 적용했다. 각 두께는 2–9 / 9–16 / 16–23 / 23–30mm 구간에서 하나씩 추출해 중간 두께도 포함한다. 공정 추출 seed=2401, 두께 추출 seed=2402다. 전체 175개 공정 그룹이며, 동일 공정의 두께 4건은 학습·평가 중 한쪽에만 배치했다.

평가 모델은 **524건 학습 / 176건 평가**로 구성했다. 최종 배포 모델은 평가 후 **700건 전체로 다시 학습**했다. 홀드아웃 지표는 평가 모델의 지표이고 최종 모델의 독립 평가 점수가 아니다.

| 타깃 | v24 그룹 홀드아웃 MAE | 고정 8건: v23 모델 MAE | 고정 8건: v24 모델 MAE |
| --- | ---: | ---: | ---: |
| 최고온도 | 1.59752°C | 3.98399°C | 1.82001°C |
| 최대 온도차 | 1.25382°C | 3.47773°C | 0.983177°C |
| 최종 경화도 | 0.000468386 | 0.000659047 | 0.000412312 |
| 공정시간 | 0.0145523분 | 0.415362분 | 0.0137307분 |

같은 8건의 물리계산 결과로 비교했을 때 최고온도 평균 절대오차는 3.984→1.820°C, 최대 절대오차는 14.367→5.408°C다. 이 8건은 v23에서 계산한 학습 외 고정 벤치마크를 재사용했다. 신규 검증 8건이라고 해석하면 안 된다. 학습 입력에 벤치마크가 포함되지 않는지 검사했고, 현재 솔버로 기준 사례를 다시 계산해 기존 검증 라벨과 일치함을 확인했다. 이미 알려진 작은 벤치마크이므로 새로운 블라인드 시험에 해당하지 않는다. 모델/데이터 구성도 달라져 이전 그룹 홀드아웃과의 단순 비교로 개선을 보증하지 않는다.

학습 라벨 계산 해상도는 nz=31, tool_nz=21, dt=2초, save=30초로 기존 256건과 동일하다. 벤치마크는 실제 AI 물리검증 해상도 nz=41, dt=1초다. 두 해상도 차이도 벤치마크 오차에 포함된다. 공정시간은 예정시간 해석식 + 학습한 냉각 지연을 사용한다.

## 연결과 실행
<!-- [NEW v24] 새 기능은 별도 파일과 독립 if로 연결한다. -->

HTML의 run_ai_async가 v24 저장 모델을 우선 로드하고 worker thread에서 캐시한다. v24 파일이 모두 없으면 보존된 v23 모델을 사용하고, v23도 없으면 기존 학습 fallback으로 이어진다. 손상된 파일이나 다른 데이터 지문은 fallback으로 숨기지 않고 오류로 차단한다. 호출자가 bundle을 제공하면 교체하지 않는다. 직접 동기 AI.run_ai 호출 경로는 이전과 같다.

v24 모델도 기존 데이터 전용 NumPy forest 형식을 사용한다. 700건 데이터의 SHA256 지문을 추가 확인한다. 모델 소스·기존 256건 데이터·학습 코드 지문과 배열 체크섬도 확인한다. sklearn pickle을 실행하거나 불러오지 않는다. 956개 입력에서 원래 학습 모델과 내보낸 모델의 예측값이 일치했다.

기존 물리 계산, 최종 후보 재계산 및 Guard를 유지했다. 실제 연결 시험에서는 후보 64개를 탐색하고 상위 2개를 물리 재계산했다. 2개 추천이 반환되고 결과 Guard를 통과했다. 자연어 LLM 추론 대신 구조화 요청을 사용한 시험이다.

Windows 실행은 기존처럼 **START_WINDOWS.bat**다. 학습 완료 파일을 포함하므로 재학습할 필요가 없다. 새 ZIP은 별도 폴더에 압축 해제하고 이전 서버를 종료한 뒤 실행한다. 재학습 명령은 `python train_physics_v24.py`. 완료된 444건 checkpoint를 재사용하며, checkpoint가 없는 새 환경에서는 444건을 직접 계산한다. 기존 generate_dataset의 256건 제한은 그대로 두고 요청에 따른 별도 700건 개발용 생성 경로를 추가했다. 외부 적격성 게이트는 열지 않았다.

범위는 기존 AS4/8552, 기본 Invar 10mm 금형 및 기본 열경계다. ramp1/ramp2=1–3°C/분, T1=105–115°C, hold1=55–65분, T2=175–185°C, hold2=115–125분, 두께=2–30mm다. 다른 재료·금형·열경계를 학습한 모델이 아니다.
