# 물리모델 대리학습 v23
<!-- [NEW v23] 실제 실행 결과와 검증 범위를 기록한다. -->

현재 물리모델로 생성된 개발 데이터 256건(64개 공정 × 두께 2/10/20/30mm)을 사용해 Random Forest 대리모델을 학습했다. 기존 데이터의 모델 해시를 확인하고 한 건을 현재 솔버로 재계산해 라벨 일치도 확인했다. LLM 가중치를 미세조정한 것은 아니다. LLM은 요청 해석, 대리모델은 후보 탐색, 물리모델은 최종 후보 재계산을 담당한다.

동일 공정의 두께별 데이터가 양쪽에 섞이지 않도록 그룹을 나눴다. 평가 모델은 192건으로 학습하고 64건으로 평가했다. 배포 모델은 평가 후 전체 256건으로 다시 학습했다. 아래 홀드아웃 수치는 평가 모델의 결과이며 배포 모델의 독립 평가 점수가 아니다.

| 타깃 | 그룹 홀드아웃 MAE (64건) | 배포 모델의 새 물리계산 MAE (8건) |
| --- | ---: | ---: |
| 최고온도 | 2.474°C | 3.984°C |
| 최대 온도차 | 1.748°C | 3.478°C |
| 최종 경화도 (0–1) | 0.000927 | 0.000659 |
| 공정시간 | 0.00956분 | 0.415분 |

공정시간은 예정 공정시간을 해석식으로 계산하고 냉각 지연만 학습하므로 전부 머신러닝으로 예측한 결과가 아니다. 새 물리계산 8건에는 학습 두께에 없는 5/15/25mm를 포함한다. 학습 라벨은 nz=31, dt=2초이며 새 검사는 실제 AI 검증과 같은 nz=41, dt=1초다. 따라서 새 오차에는 수치 해상도 차이도 포함된다. 8건은 제한적인 대표 사례이며 전체 입력 범위의 정확도를 보증하지 않는다.

25mm 사례에서 최고온도를 **14.367°C 과소예측**했다. 최종 후보는 기존 물리 재계산과 Guard를 계속 통과해야 한다. 대리모델의 순위 오차로 좋은 후보가 탐색에서 누락될 가능성도 있다. 이 모델은 개발용 후보 탐색에 사용하며 제조 판정이나 외부 실험 검증을 대신하지 않는다. qualified 및 external_validation_passed는 false로 유지했다.

## 적용 범위와 실행
<!-- [NEW v23] 기존 실행 방법을 유지한다. -->

AS4/8552, 기본 Invar 10mm 금형과 기본 열경계 조건에서 사용한다. ramp1/ramp2=1–3°C/분, T1=105–115°C, hold1=55–65분, T2=175–185°C, hold2=115–125분, 두께=2–30mm다. 다른 재료·금형·열경계에 대한 학습은 수행하지 않았다.

START_WINDOWS.bat 실행 방법과 v22 UI는 같다. 학습 파일을 이미 포함하므로 사용자 PC에서 재학습할 필요가 없다. HTML AI 실행의 run_ai_async가 저장 모델을 worker thread에서 로드·캐시한다. 호출자가 bundle을 제공하면 그 모델을 유지한다. 저장 모델이 없으면 기존 학습 경로를 사용하며, 해시 불일치나 파일 손상이면 오류로 차단한다. 직접 동기 AI.run_ai를 호출하는 기존 경로에는 자동 로드 변경을 적용하지 않았다.

forest_arrays.npz는 pickle 없이 NumPy 배열로 저장한다. 모델·원본 데이터·학습 코드 지문과 파일 체크섬을 확인한다. Python 마이너 버전 간 pickle 의존을 제거했지만 실제 Windows Python 3.14 실행 검증은 아직 수행하지 않았다. Linux Python 3.12에서 학습 및 검사를 실행했다.

재학습: 준비된 Python 환경에서 `python train_physics_v23.py`. 기본 개발 데이터 256건으로 모델을 다시 만들고 그룹 평가·새 물리계산 8건·배포를 위한 배열 내보내기를 수행한다. 기존 물리식, AI.py, AI_guard.py와 개발 CSV는 변경하지 않았다.
