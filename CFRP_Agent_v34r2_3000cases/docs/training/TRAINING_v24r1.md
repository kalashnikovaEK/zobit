## 판정과 사용 범위

현재 단일 재료 AS4/8552, Invar 10 mm, 고정 기본 열경계에서 공정 후보를 빠르게 탐색하고 최종 후보를 물리 계산으로 다시 확인하는 대회 MVP에는 3,000건을 우선 충분한 학습 규모로 판단한다. 보편적인 최소 건수나 제조 인증 기준이 아니다. 데이터 수를 더 늘리기보다 실제 Ollama 요청·발표 시연 경로 확인이 다음 우선순위다.

현재 입력 영역: 1/2차 승온속도 각각 1–3 °C/min, 1차 유지온도 105–115°C, 2차 유지온도 175–185°C, 1차 유지시간 55–65분, 2차 유지시간 115–125분, 두께 2–30 mm. 금형·접촉계수·재료가 바뀌는 모델은 이번 학습 대상이 아니다. 학습 범위 밖 일반화는 검증하지 않았다.

이 실행본은 v24 폴더 정리본을 바탕으로 한 독립 v24r1이다. 다른 대화에서 제작한 v33/v34의 자연어 검증 개선·승인 화면을 통합한 버전이 아니다. 기존 v24 자연어 검증 결함도 이번 학습으로 수정되지 않는다. 최신 실행본에 옮길 때는 물리/학습 코드와 데이터 지문 호환을 확인해야 한다.

## 데이터 생성과 분리

기존 700건을 보존하고 2,300건을 실제 물리 솔버로 추가 계산했다. 총 750개 공정 그룹, 3,000개 입력이다. 동일 6개 공정조건에 속하는 4개 두께 변형을 한 그룹으로 묶었다. 중복 입력과 비유한 값은 0건이다. 물리 계산식과 material.json은 수정하지 않았다.

그룹 홀드아웃: 2,248건 학습 / 752건 평가. 평가 후 배포 모델을 전체 3,000건으로 재학습했다. 이어 학습에 사용하지 않은 별도 25개 공정 그룹 × 4개 두께 = 100건을 새로 계산했다. 100건은 700건 및 3,000건 모델에 동일하게 적용했으며, 학습 데이터와 공정 그룹도 겹치지 않는다. 이 100건으로 하이퍼파라미터를 고르거나 재학습하지 않았다.

학습 정답: 복합재 31셀, 금형 21셀, 시간 간격 2초. 별도 100건 평가 정답: 복합재 41셀, 금형 21셀, 시간 간격 1초. 따라서 아래 오차에는 해상도 차이도 포함된다. 실제 실험 오차가 아니다. 재생성 난수 시드는 실행 스크립트·JSON 감사 기록에 있다.

## 같은 신규 100건에서 비교

| 항목 | 기존 700건 MAE | 신규 3,000건 MAE | 평균오차 감소 | 신규 최대 절대오차 |
| --- | ---: | ---: | ---: | ---: |
| 최고 내부온도 | 1.6625 °C | 1.0613 °C | 36.2% | 7.0768 °C |
| 최대 온도편차 | 1.1272 °C | 0.5298 °C | 53.0% | 4.5204 °C |
| 최종 경화도 | 0.0450 %p | 0.0259 %p | 42.6% | 0.0828 %p |
| 공정시간 | 1.1485 초 | 0.5929 초 | 48.4% | 1.5507 초 |

경화도 %p는 0–1 경화도를 백분율로 표시한 값의 차이다. 최고온도 최대오차 약 7.08°C가 남으므로 대리모델 단독으로 최종 제약 충족을 판정하지 않는다. 기존 고정 8건에서는 최고온도 MAE가 1.820→1.272°C로 줄었지만 최대오차는 5.408→5.552°C로 소폭 증가했다. 모든 조건에서 오차가 감소했다고 주장하지 않는다.

## 실제 연결과 시험

- 별도 3,000건 저장소를 추가하고 async_runtime_v17.py에 우선 로드용 독립 if만 삽입했다. 새 저장소가 없으면 기존 700건, 이후 256건 경로를 유지한다. 손상된 파일은 오류로 차단한다.
- 기존 데이터·모델·물리 코드·UI·Windows 실행 파일을 보존했다. 저장 형식은 기존 NumPy 배열 기반이며 pickle을 사용하지 않는다.
- 원 학습 모델과 저장 후 로드 모델을 3,256개 입력에서 대조했고 모든 타깃 최대 차이는 0이다.
- 전체 Python 시험 26개 통과. 기존 700건 시험은 새 저장소를 비활성화하여 보존된 fallback 경로를 시험하고, 새 3,000건 경로는 별도 시험한다.
- 시간 최소화·최고온도 최소화·온도편차 최소화 각 256개 후보 탐색을 실제 실행했다. 목표별 4건, 총 12건의 후보 물리 재계산을 수행했고 목표별 추천 3건을 반환했다. 세 목표 모두 결과 Guard 통과.
- 실제 HTTP의 수동 계산·실측 경계 계산·AI 응답 경로도 통과했다. LLM 해석은 모의하거나 구조화 요청을 공급했다. 실제 Ollama 추론 시험은 아니다.

| 3,000건 생성·학습·저장·Agent 자동 로드 | 실제 Ollama 자연어 추론 |

| 기존 물리 코드·700건 자산 보존 | v33/v34 확인 절차와 통합 |

## 파일과 실행

새 폴더에 압축을 해제하고 START_WINDOWS.bat를 실행한다. Windows 표준 64비트 Python 3.14 설치가 필요하다. 기존 서버는 종료한다. 모델은 이미 학습돼 있으므로 사용자가 재학습할 필요는 없다.

- 학습 스크립트: app/train_physics_v24r1.py
- 모델 로더: app/surrogate_store_v24r1.py
- 전체 3,000건 CSV: app/artifacts/development_cases_3000_v24r1.csv
- 추가 계산 체크포인트: app/artifacts/generated_2300_v24r1.jsonl
- 별도 평가 체크포인트: app/artifacts/validation_100_v24r1.jsonl
- 모델·평가표·감사 기록: app/artifacts/trained_surrogate_v24r1/
- 실행 로그: docs/evidence/logs/training_v24r1.log, tests_v24r1.log

재학습은 app 폴더에서 `python train_physics_v24r1.py`. 기존 체크포인트가 있으면 검증 후 재사용한다. 원본처럼 CPU용 Random Forest를 사용한다. 학습 환경은 Linux Python 3.12이며 Numba 0.68.0으로 생성 가속했다. 학습 산출물은 기존 포터블 배열 형식이다.

README의 과거 v16 안내에 있는 tests/설치 파일 제외 문구는 현재 구성에 적용되지 않는다. 현재 tests와 Windows 설치 파일은 포함돼 있다. 별도 논문 보정 CLI나 보정 완료 계수는 이번 작업으로 추가되지 않았다. `external_validation_passed=false`를 유지한다.
